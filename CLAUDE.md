# Bounded-Brainstorming-Finetune

Spec and (later) data, training and eval for a small fine-tune that does bounded brainstorming: N novel, format-matched items from a task, priors and a format. Read `README.md` and `docs/schema.md` first.

- Release tier: small (`v1.0`, `v1.1`, ...).
- Public repo. Do not commit private priors such as unreleased episode lists or personal CVs. Keep them in a gitignored `data/private/`.
- Python via `uv`.
